## Italiano
Prima release pubblica del bridge Rust LSC Smart Connect/Battletron per SignalRGB. Login QR, sincronizzazione account, stream LAN autenticato, quattro zone e pannello di riconnessione. Include backup configurazione con recupero del file corrotto e supervisore di riavvio. Verificati 61 test Rust, 9 test di parità, 82 controlli plugin ed E2E; otto luci osservate online nel collaudo locale.

## English
Initial public release of the Rust LSC Smart Connect/Battletron bridge for SignalRGB. QR login, account refresh, authenticated LAN streaming, four zones and reconnect panel. Includes recoverable configuration backups and a restart supervisor. Verified: 61 Rust tests, 9 parity tests, 82 plugin checks and executable E2E; eight lights observed online in the local check.

The Windows x64 ZIP contains the executable and prebuilt plugin: Rust and Node.js are not required for release installation. Existing LSC Wi-Fi pairing is required. Bluetooth LotusLamp is not included. Read the IT/EN guides before installation; configuration/session files must remain private.
